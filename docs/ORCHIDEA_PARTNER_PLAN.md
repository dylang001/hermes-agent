# Orchidea Partner Plan

Partners = leverage without acquiring Success.ai-style spray platforms.

## Guiding rules

1. Partners must accept **approval-gated** outreach and suppression sharing.  
2. Prefer referral / specialist capacity over lead-gen spam networks.  
3. No partner gets SpaceMail credentials or cookie/session access.  
4. Data mutualism: share anonymized vertical learnings, not full contact dumps without consent/policy.

## Partner types (phased)

| Phase | Partner type | Hermes use |
|---|---|---|
| Now | Internal only (Dylan + Hermes + ClickUp) | Run MVP end-to-end |
| Next | Deliverability / DNS specialist | Seed tests, DMARC |
| Next | Vertical SMEs (med spa ops, booking vendors) | Proof peer-review |
| Later | Local creatives / landing freelancers | Soft fulfillment after booked calls |
| Later | Compliant list partners | Only with contractual suppression + consent docs |

## Explicit non-partners

- Success.ai and lookalike “unlimited email” platforms  
- Cookie-jar / CAPTCHA farms  
- Bulk LinkedIn/Reddit engagement agencies for cold scale  

## Handoff after positive reply

1. Hermes alerts + call prep brief  
2. Dylan owns sales call  
3. Optional fulfillment partner only after scoped SOW  
4. Outcome logged → weekly learning  

## Metrics for partner keep/kill

- Contribution to qualified bookings  
- Zero complaint spikes attributable to their lists  
- SLA on proof/asset turnaround

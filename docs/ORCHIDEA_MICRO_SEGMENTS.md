# Orchidea Micro-Segments

Start narrow. Expand only when A-tier yield and reply quality justify it.

## Segment 0 (MVP): Multi-location med spas

| Field | Spec |
|---|---|
| **Name** | `medspa_multi_location_us` |
| **Who** | Independent US medical spas / aesthetics groups with **2+ locations** (or clear multi-site booking) |
| **Why first** | Budget + booking complexity; demand leakage compounds across sites; proof assets transfer |
| **Geo start** | Cities already in gtm target set: NYC, LA, Miami, Dallas, Houston — then expand |
| **Buyer** | Owner / managing partner / operations lead |
| **Primary signals** | Cross-location ads, inconsistent booking CTAs, intake hiring, review friction |
| **Disqualify** | National franchise brands, PE rollups, hospital aesthetics depts, non-US |
| **Proof style** | Mobile booking teardown, location inconsistency note, ad→page friction |
| **Outbound mode** | Plain-text 3-touch (not proposal engine unless separately approved) |

### Discovery queries (lean)

- Google/Places: “med spa” + city + review for multi-site brands  
- Site: footer/location pages with ≥2 addresses  
- Hiring: “patient coordinator” / “front desk” near brand name  
- Ads: Transparency search on confirmed domain only after shortlist

### Ideal evidence pack before enrich

1. Location list URL  
2. One booking friction screenshot or HTTP note  
3. Optional ads confirm  
4. Timing trigger (hire or new location ≤90d preferred)

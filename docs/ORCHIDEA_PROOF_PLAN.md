# Orchidea Proof Plan

Proof = a **truthful, small artifact** that makes the soft CTA real. No fabricated audits.

## Proof types (MVP allow-list)

| Type | When | Cost |
|---|---|---|
| Annotated mobile screenshot of booking CTA | Funnel leak | Hermes browser / Playwright shortlist |
| 5-line booking path teardown | Phone-only or multi-step friction | Manual + URLs |
| Location inconsistency note | Multi-loc segment | HTTP compare of 2 locations |
| Ad→landing mismatch note | Confirmed ads | Serper/Transparency + page |
| Review friction quote | Public reviews | Quote + link (no scraped private data) |

## Production rules

1. Proof must match the **same** observation used in E1/E2.  
2. Store asset URL + capture timestamp in evidence log.  
3. Cold E1 usually **offers** proof (“want me to send…”) rather than attaching it.  
4. E3 may deliver the artifact after interest or as final value touch.  
5. Proposal-engine seven-asset packs are **out of MVP scope** until plain-text loop works.

## Anti-patterns

- Stock screenshots / placeholders  
- Invented “you’re losing $X/mo” graphics  
- Competitor disparagement without public evidence  
- Tracking pixels as “proof of open”

## Ready-for-draft gate

Tier A requires either an existing proof asset **or** a 15-minute brief that a human/agent can execute before send week.
